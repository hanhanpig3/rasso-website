核心功能详解

六大核心能力，构建完整的桌面工作效率流

⚡ 毫秒级极速响应

基于拼音首字母匹配与模糊评分算法，输入即搜索结果即时呈现。待机内存占用极低，启动到可用仅需数毫秒。数学表达式、时间戳、Base64 一键转换，无需切换应用。

⚡
输入 → 计算 → 复制
三步完成，全程无需鼠标

🎨 三态流线交互

待机横条（56px）几乎隐形，搜索时智能扩展到结果列表高度，需要完整功能时展开至 600px 窗口。Win11 Acrylic 毛玻璃材质配合物理弹簧动效，每一次形态转换都优雅流畅。

🪟
56px → 自适应 → 600px
形态随需而变

🎯 命令路由引擎

关键词模糊评分、正则表达式匹配、URL/IP 自动识别，拖入图片自动走 OCR，拖入 JSON 自动走格式化。你的意图就是命令，无需记忆复杂语法。

🔀
拖拽 → 识别 → 自动执行
意图驱动的命令路由

📌 截图与桌面贴图

内置全屏选框截图工具，按 Ctrl+Shift+P 将剪贴板图片原生物理置顶在桌面上。支持无级滚轮缩放、透明度调节与拖拽，是标注、对比、参考的理想工具。

📌
截图 → 贴图 → 悬浮桌面
永不错过的参考信息

🐫 小驼峰变量命名

内置高频编程分词库与同义词笛卡尔积装配引擎，支持 camelCase / PascalCase / snake_case / kebab-case 四种规范实时秒出。独立 API 配置面板，支持自建 HTTP / OpenAI / 百度等接口。

🐫
中文输入 → 四种命名规范
实时秒出，开箱即用

☁️ WebDAV 多端同步

支持标准 WebDAV 协议自建私有云同步，配置与数据完全归个人所有。无需依赖第三方云服务，隐私数据安全可控。

🔒
私有云 · 数据主权
你的数据，你的规则
